# HelpDesk Inteligente — Vendas Online

Sistema de atendimento ao cliente para uma loja online, desenvolvido em fases:

- **Fase 1** — Classificação da dúvida do cliente com Machine Learning (categoria, prioridade e resposta base).
- **Fase 2** — Resposta humanizada com LLM *(em breve)*.
- **Fase 3** — Imagem + consulta de pedido *(em breve)*.
